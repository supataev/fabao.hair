# fabao.hair

Website of Fabao, the official distributor of ZhangGuang 101, DekoHair and Follicell in Kyrgyzstan.

- `index.html`: public site (Russian / Kyrgyz), hosted on GitHub Pages.
- `admin/`: staff panel at fabao.hair/admin for products, brands and site texts.
- `supabase/schema.sql`: database tables, security rules and starter content.
- `data/content.json`: starter content shown until the database is connected.
- `assets/img/fabao-wordmark.svg`: the Fabao wordmark (recolor with CSS `currentColor` or as a mask).

Setup: [docs/SETUP.md](docs/SETUP.md). Staff guide (RU): [docs/STAFF_GUIDE.md](docs/STAFF_GUIDE.md).

No build step: edit the files and push to `main`.
